Legacy & 32-bit

We believe older hardware still has life left. MorrowOS will support it.

Legacy Build

A dedicated build for older machines that still rely on 32-bit processors and BIOS firmware. Based on a Linux distribution that continues to support 32-bit architectures.

  • 32-bit CPU support
  • BIOS boot compatibility
  • Optimized for lower RAM
  • Lighter package selection

Future Plans

As MorrowOS matures, we plan to extend 32-bit support to additional Linux bases where practical. Our main build will always target 64-bit hardware, but we won't leave older systems behind.

  • Debian-based legacy builds
  • Additional Linux base support
  • Ongoing hardware compatibility work
